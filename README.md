# Психологически програми — платформа за резервации, пакети и събития

Онлайн платформа за резервации на психологически консултации, предплатени
пакети часове и събития/курсове. Скеле, изградено по одобрената техническа
спецификация (`docs/spec.md`).

## Структура

```
backend/    Laravel 13 REST API (PHP 8.4) — auth, резервации, пакети, събития, админ
frontend/   Vue 3 + Vite SPA — публичен сайт, потребителски профил, админ панел
docs/       Оригиналната спецификация
```

Съгласно спецификацията, в продукция админ частта живее на отделен
поддомейн (`admin.<domain>`). За скелето админ изгледите (`/admin`,
`/admin/bookings`) са част от същото SPA и се пазят зад проверка на роля
(`role: admin|editor`) — при нужда лесно се изнасят в отделен Vite build.

## Роли

- **Admin** — пълен достъп до всички модули, включително управление на потребители.
- **Editor** (психолог) — управлява график, резервации, събития и съдържание.
- **User** — резервира часове, купува пакети/билети, управлява собствения си профил.

## Backend (Laravel)

```bash
cd backend
composer install
cp .env.example .env   # вече конфигуриран за sqlite + localhost URLs
php artisan key:generate
php artisan migrate --seed
php artisan serve
```

Сийдърът създава:

| Роля   | Имейл                | Парола     |
|--------|----------------------|------------|
| Admin  | admin@example.com    | password   |
| Editor | editor@example.com   | password   |
| User   | user@example.com     | password   |

плюс таксономия "Тип помощ", 2 пакета, 2 седмици свободни часове и 1 примерно събитие.

За продукция сменете `DB_CONNECTION` на `mysql`/`mariadb` в `.env` (спецификация §8),
и попълнете `STRIPE_SECRET` / `STRIPE_WEBHOOK_SECRET` за плащанията.

Ключови бизнес правила, вградени в API-то (спецификация §7):

- Резервация е възможна само за свободен слот (заключва се с `lockForUpdate`).
- Всяка нова заявка тръгва в статус „чакаща одобрение“; потвърждение/отказ/преместване
  се извършват само от admin/editor (`role` middleware).
- При потвърждение с активен пакет часовете в пакета се намаляват с 1.
- Всички цени са в EUR.
- Нерегистриран потребител се създава автоматично при резервация и трябва да
  потвърди имейла си, преди да влезе в профила си.
- Вътрешните бележки (`internal_note`) никога не се връщат в публичните ендпойнти.
- Замразен потребител (`status: frozen`) не може да прави нови заявки или да
  редактира профила си.
- Билет за събитие се купува само при налични свободни места (`spots_taken` < `capacity`).

## Frontend (Vue 3 + Vite + Tailwind v4)

```bash
cd frontend
npm install
cp .env.example .env   # VITE_API_URL сочи към backend
npm run dev
```

Дизайн системата (тъмна, кинематична, топла палитра) е дефинирана като
CSS токени в `src/style.css` (спецификация §9): фон `#171310`, повърхност
`#211B16`, акцент `#B8874A`, шрифтове Cormorant Garamond (заглавия) +
Poppins (текст/UI).

Начална страница (`src/views/HomeView.vue`) следва точно sitemap-а от
спецификация §10: хиро слайдер, За мен, Услуги, Как протича, Пакети и цени,
Събития (данните идват от `/api/events`), Отзиви, CTA банер, футър —
с одобрените текстове от §11.
